# 销售助手评测问题集（Golden Set）

> 用途：**上线验收与回归测试的唯一标准**。每次更新知识库语料、替换真实数据、升级模型后，用本问题集全量跑一遍。
> 评分规则：每题按"数据源正确 / 数值正确 / 结论正确 / 无幻觉"四项判定，任何一项失败即该题不通过。整体通过率 ≥90% 方可发布。
> 使用方式：人工向 Agent 提问（或走 API 压测脚本），对照"期望要点"逐项核对。

## 评分与记录

- 通过标准：四项全对为 PASS；数据源错/数值错/幻觉 = FAIL（严重）；结论偏差 = WARN。
- 每次评测结果记入 `评测记录`（建议格式：日期/问题号/结果/失败原因），连续两次同题失败需排查数据或提示词。
- 本问题集本身也要维护：数据替换为真实数据后，所有期望数值必须同步更新（见《数据资产使用总说明》第 6 节）。
