# 客户画像与 ICP 判定标准

> 适用范围：市场部线索分发、销售线索评估与推进决策。本标准与《销售方法论与商机资质判定手册》（MEDDIC）配套使用：
> **ICP 决定"这个线索值不值得跟"（资格准入），MEDDIC 决定"这个商机能不能赢单"（推进质量）**。
> 台账"阶段流转规则"sheet 中"ICP画像匹配"的判定依据即为本文件。

## 一、总体 ICP（公司级画像）

| 维度 | 标准 | 权重 |
|------|------|------|
| 行业 | 智能制造、金融服务、专业服务（教育/咨询/医疗）、连锁零售与餐饮、物流与汽车后市场 | 高 |
| 员工规模 | 300–5000 人（客服/IT/售后团队规模 ≥10 人） | 高 |
| 数字化基础 | 已有 CRM/ERP/OA 任一系统，或有明确数字化预算 | 中 |
| 服务压力 | 客服咨询量日均 ≥500 次，或工单量日均 ≥100 单 | 高 |
| 预算信号 | 年度 IT 预算中可明确 ≥5 万元用于本类采购 | 高 |
| 决策结构 | 有明确的客服/IT 负责人（可触及决策链） | 中 |

**一票否决项（任一命中即不入池）**：
1. 客户明确倾向纯免费工具（无付费意愿信号）；
2. 数据必须存放境外且不接受中国香港/海外节点（我方私有化部署在国内机房）；
3. 员工规模 <100 人且无增长迹象（客单价撑不起获客成本）；
4. 采购由集团统管且集团已战略绑定其他供应商。

## 二、分产品线 ICP

### 智能客服平台
- **目标角色**：客服总监、呼叫中心负责人、CIO
- **最佳画像**：全渠道接入需求（微信/网页/电话≥3个）、日均咨询量 ≥1000 次、对质检有合规要求（金融/医疗行业优先）
- **版本匹配**：≤50 席→标准版；≤200 席且需知识库问答→专业版；私有化/SLA 合规→旗舰版
- **负向信号**：只想解决单一渠道（更适合单点工具）、客服外包占比 >80%（决策权在外包商）

### 工单系统
- **目标角色**：IT 服务负责人、售后总监、运维经理
- **最佳画像**：多级派单场景（网点/门店/工程师现场）、日均工单 ≥100、需要 SLA 时限管理与审计（ISO/行业合规）
- **版本匹配**：≤30 人 IT/售后→团队版；不限人数或需审计日志→企业版
- **负向信号**：工单量 <30/日（Excel 即可管理）、已有 ITSM 大厂产品且在合同期

### 企业知识库
- **目标角色**：知识管理负责人、HR 培训负责人、质量/合规负责人
- **最佳画像**：SOP/制度文档 ≥500 篇需结构化管理、多部门知识沉淀需求、需要 AI 问答入口降低检索成本
- **版本匹配**：≤500 人→标准版；私有化与贡献激励体系→企业版
- **负向信号**：团队协作文档需求为主（会被 Notion/飞书文档分流，对应输单原因"需求放弃"）

## 三、线索分级（P0/P1/P2）

| 等级 | 定义 | 动作要求 |
|------|------|----------|
| P0 | 命中分产品线 ICP 最佳画像 + 服务压力证据 + 有明确预算窗口 | 24 小时内首触，销售负责人亲自跟进 |
| P1 | 命中总体 ICP，1–2 个次要维度信息缺失 | 3 个工作日内补全信息并触达 |
| P2 | 部分命中（行业或规模单项达标） | 进入 nurture 池，月度培育触达，不占用销售主线 |

**分级与 MEDDIC 评分的映射**：P0 ≈ MEDDIC 5–6 分；P1 ≈ 3–4 分；P2 ≈ 1–2 分。台账"MEDDIC评分"列即此口径。

## 四、行业优先级（结合区域与竞品动态）

基于输赢单分析（2026-06~08）与区域产品透视：
1. **华北智能制造/建筑**：竞争烈度低，旗舰版接受度高——P0 密集区；
2. **华南连锁零售/餐饮/药房**：知识库渗透率低、竞品关注少——知识库增长区；
3. **华东（重点防守）**：智齿促销期（见竞品追踪台账），客服平台正面单优先级下调，转打"私有化+SLA+组合"场景；工单与知识库仍可正面竞争；
4. **西南**：客户规模偏小为主，标准版/团队版为主力，控制跟进成本。

## 五、使用规则（对 Agent）

1. 用户询问"这个公司值不值得跟"时：先查台账确认是否已有线索及历史状态，再按本文件逐维度比对用户提供的信息，输出 P0/P1/P2 分级与缺失维度清单；
2. 缺失维度不要臆测，明确列出"需要向客户确认的问题清单"；
3. 分级结论要与台账现有 MEDDIC 评分交叉印证，不一致时提示用户复核；
4. "负向信号"命中时如实提示风险并引用对应输单案例作证据。
