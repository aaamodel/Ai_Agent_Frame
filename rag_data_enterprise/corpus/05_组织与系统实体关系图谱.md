### 1.2 线索流转的部门接力关系

```
线索（市场部首次筛选） → MQL（市场部→销售部交接） → SQL（销售部）
→ 商机（销售部 + 售前） → 方案验证（售前） → 商务谈判（销售部 + 销售部负责人）
→ 赢单 / 输单（销售部复盘）
```

- **线索首次筛选的责任部门是市场部**：依据《客户画像与 ICP 判定标准》完成 ICP 画像匹配与
  P0/P1/P2 分级，通过后成为 MQL 并移交销售部；
- 销售部承接的是 MQL 之后的**首次有效触达与需求确认**，属于二次确认，不是首次筛选；
- 搁置与公海回收由销售运营负责：连续 45 天无响应且两次跟进未回复 → 置为搁置；
  搁置超 90 天 → 移入公海并清空负责人。

### 1.3 关键口径澄清（易错点）

> **CRM 台账中的「负责人」字段 = 该线索当前的销售侧跟进人；**
> **「线索首次筛选的责任部门」= 市场部。**
> 两者不是同一概念：一条线索可以"筛选由市场部完成、负责人是某位销售"。

## 第二章 系统间集成关系

### 2.1 CRM 系统 ↔ IT 服务台（工单系统内部实例）

**结论：已打通，但为「主数据单向权威 + 服务记录回查」的有限打通，不是全量双向同步。**

| 方向 | 内容 | 方式 | 频率 |
|------|------|------|------|
| CRM → 工单系统 | 客户主数据（客户编码、客户名称、所属行业、区域、销售侧负责人） | 服务总线 API 推送 | 实时（变更触发） |
| 工单系统 → CRM | 服务工单统计（工单量、SLA 达成率、未闭环工单数）以只读形式回写客户 360 视图 | 服务总线 API 回写 | 每 15 分钟增量 |
| 主数据归属 | **客户主数据以 CRM 为唯一主数据源（MDM）**，工单系统不新建客户 | — | — |

**未打通的部分（边界）**：

1. 工单系统**不会**自动生成或更新商机；
2. 工单系统**不回写** CRM 的「状态」「MEDDIC评分」等业务字段；
3. CRM 的销售侧跟进动作不同步到工单系统；
4. 两套系统的 SLA 相互独立：工单 SLA 只对 IT 服务台生效，不适用于商机跟进时效。

### 2.2 采购与合同审批系统（PAS）↔ 财务共享系统（FSS）

**数据流（正向）**

```
PAS 审批通过（采购申请/合同/付款申请）
  → 经服务总线推送至 FSS，生成「应付单 / 付款申请」
  → FSS 三单匹配（合同 + 发票 + 验收/收货记录）
  → 匹配通过后按付款日（每周三、周五）经银企直连付款
```

**数据流（反向）**

```
FSS 将付款状态、付款日期、会计凭证号回写 PAS
  → PAS 单据置为「已付款」并归档
  → 日终对账：FSS 与 PAS 按单据号逐笔核对，差异生成对账差异表
```

**要点**

- PAS 只负责「审批与发起」，不负责账务处理与资金支付；
- FSS 只负责「核算与支付」，不负责采购审批；
- 发票与开票信息由 FSS 统一管理，PAS 不存储权威开票信息；
- 审批链按金额分级（<1 万 / 1~10 万 / ≥10 万），详见《内部业务系统使用手册》4.3。

### 2.3 其他系统间关系

| 主体 | 关系 | 客体 | 说明 |
|------|------|------|------|
| OA 系统 | 提交 | FSS（报销单、预算单、成本中心申请） | OA 是流程入口，FSS 是核算与权威数据方 |
| FSS | 回写 | OA（付款状态、报销进度） | 员工在 OA 查看进度 |
| FSS | 同步 | CRM（回款状态、应收账期） | 销售可在 CRM 查看客户回款情况 |
| CRM | 发起 | FSS（开票申请） | 销售在 CRM 提交，FSS 执行开票 |
| CRM | 主数据源 | 客户信息（MDM） | 其他系统只读同步，不得反向改写 |
| PAS | 同步 | CRM（供应商与合同编号） | 用于商机与合同的关联查询 |
| 企业微信 | 统一身份入口 | 全部内部系统 | 单点登录与移动端工作台 |
| 企业知识库（内部版） | 承载 | 各制度文档与 SOP | 文档的发布与权限归口 |

## 第四章 数据上下游（血缘）

| 数据对象 | 上游（产生方） | 下游（消费方） |
|----------|----------------|----------------|
| 客户主数据 | CRM（主数据源） | 工单系统、FSS、PAS |
| 线索与商机 | 市场活动/官网/转介绍 → CRM | 销售分析报表（`raw_data/sales_intel`） |
| 合同与回款 | CRM → FSS | 销售目标与考核、经营分析 |
| 付款记录 | PAS → FSS | 预算执行、成本中心核算 |
| 服务工单 | IT 服务台 | CRM 客户 360 视图（只读） |
| 开票信息 | FSS（权威源） | CRM 客户档案（只读同步） |
