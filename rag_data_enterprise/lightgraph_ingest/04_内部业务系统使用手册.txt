# 内部业务系统使用手册

> 版本：v1.0 | 维护人：信息技术部（各系统归口部门联合维护）| 更新节奏：系统版本发布后 5 个工作日内
> 适用范围：全体员工。本文件回答"某个内部系统能做什么、怎么用、权限归谁管"这一类问题。
> **系统之间的关系、数据流转、职责归属不在本文件**，见《组织与系统实体关系图谱》。

---

## 第一章 系统清单与归口

| 简称 | 全称 | 主要用途 | 归口部门 | 使用范围 |
|------|------|----------|----------|----------|
| CRM 系统 | 客户关系管理系统 | 线索、客户、商机、合同与回款的主数据管理 | 销售运营 | 销售、售前、市场 |
| OA 系统 | 办公自动化系统 | 请假、加班、报销、用印、公告、人事流程入口 | 人力资源部 + 行政部 | 全员 |
| IT 服务台 | 工单系统（内部实例） | IT 报障、运维工单、SLA 时限管理 | 信息技术部 | 全员 |
| PAS | 采购与合同审批系统 | 采购申请、询比价、合同审批、供应商准入、付款申请发起 | 采购部 | 全员（按金额分级） |
| FSS | 财务共享系统 | 开票、发票、报销核算、付款、预算、成本中心 | 财务部 | 全员（按角色） |
| 企业知识库 | 企业知识库（内部版） | 制度、SOP、产品资料、培训课件的结构化管理与 AI 问答 | 人力资源部 + 信息技术部 | 全员 |
| 企业微信 | — | 统一身份入口与移动端工作台 | 信息技术部 | 全员 |

**命名约定（重要）**：公司对外销售的产品线包含「工单系统」，内部 IT 报障平台是该产品的内部部署实例。
提及"内部的工单系统"时通常指 IT 服务台；提及"工单系统产品/版本定价"时指对外销售的产品线，
两者不可混答（产品定价见《公司产品知识库》第三章）。

## 第二章 CRM 系统

### 2.1 承载的业务对象

- **客户线索台账**：线索编号格式为 `LD-YYYYMM-XXX`（例：`LD-202606-004`），为主键不可修改；
- **商机与阶段流转**：线索 → MQL → SQL → 商机 → 方案验证 → 商务谈判 → 赢单/输单；
- **MEDDIC 评分**：六要素各按「明确 2 分 / 部分明确 1 分 / 未知 0 分」计分，满分 12 分；
- **市场活动**：活动编号格式为 `MA-YYYYMM-XX`，活动产出的线索回写至台账「来源渠道」字段。

### 2.2 关键字段口径（与销售制度文档一致）

| 字段 | 取值 | 依据 |
|------|------|------|
| 线索编号 | `LD-YYYYMM-XXX` | 台账字段字典 |
| 行业 | 制造业 / 零售连锁 / 金融服务 / 汽车零部件 / 医疗器械 / 物流运输 / 教育服务 / 能源化工 | 《客户画像与 ICP 判定标准》 |
| 区域 | 华北 / 华东 / 华南 / 西南 | 台账字段字典 |
| 来源渠道 | 市场活动 / 官网留资 / 转介绍 / 电销 / 内容营销 | 台账字段字典 |
| 状态 | 线索 / MQL / SQL / 商机 / 方案验证 / 商务谈判 / 赢单 / 输单 / 搁置 | 《销售方法论与商机资质判定手册》1.2 |
| MEDDIC评分 | 0~12 分，A(10~12)/B(7~9)/C(4~6)/D(0~3) | 同手册 3.1 / 3.2 |
| **负责人** | 该线索当前的**销售侧跟进人** | ≠ 线索首次筛选部门（市场部） |

### 2.3 权限与数据范围

- 按「区域 + 角色」授权：销售默认仅可见本人负责的线索与商机；
- 销售部负责人可见本部门全部数据；销售运营可见全量并负责公海调配；
- 客户主数据以 CRM 为唯一主数据源（MDM），其他系统只做只读同步。

## 第三章 OA 系统

### 3.1 主要功能

| 模块 | 说明 |
|------|------|
| 假期管理 | 年休假、事假、病假等申请与额度查询（规则见《人事制度与员工手册》第二章） |
| 报销 | 费用报销单提交（核算与付款在 FSS） |
| 用印与证照 | 公章、合同章用印申请，需二级审批 |
| 人事流程 | 转正、离职、账号开通/停用申请 |
| 公告与制度 | 公司制度发布与确认签收 |
| 预算与成本中心申请 | 提交入口（审批在 FSS） |

### 3.2 权限控制

- 采用「角色 + 组织架构」双维度授权：角色决定可见模块，组织架构决定数据范围；
- 敏感流程（用印、证照借出、超标准报销）默认需二级审批，不允许自审自批；
- 权限变更须由部门负责人在 OA 提交申请，信息技术部 1 个工作日内生效；
- 离职账号在最后工作日 18:00 前统一停用（见《人事制度与员工手册》3.5）。

### 3.3 移动端

支持企业微信工作台免密登录，可完成审批、请假、报销单提交；
用印申请与证照借出不支持移动端。

## 第四章 采购与合同审批系统（PAS）

### 4.1 功能范围

| 功能 | 支持 | 说明 |
|------|------|------|
| 采购申请与提单 | 支持 | 常用物料、IT 设备、市场服务、外包服务 |
| 询比价与供应商比选 | 支持 | 单笔 ≥5 万元须至少 3 家比价 |
| 合同审批 | 支持 | 标准合同模板库；非标条款需法务会签 |
| 供应商准入与信息变更 | 部分支持 | 准入申请可发起，资质审核需采购部线下完成 |
| 付款申请发起 | 支持 | 推送 FSS 后统一支付 |
| 发票与账务处理 | 不支持 | 归 FSS |

### 4.2 移动端能力（企业微信工作台 / 移动端 H5）

**移动端已支持**：

1. 提交采购申请单（含常用模板一键提单）；
2. 审批（通过 / 驳回 / 加签 / 转交）；
3. 上传附件与拍照上传（发票、报价单、验收照片）；
4. 扫码识别资产编号与合同编号；
5. 催办与消息提醒、查看审批进度。

**移动端暂不支持（须 PC 端）**：

1. 批量导入采购清单（Excel 模板导入）；
2. 供应商准入资质提交与信息变更；
3. 合同用印申请（涉及印章实物与法务会签）；
4. 单笔金额 ≥50 万元的合同终审（须 PC 端双因素确认并留痕）；
5. 询比价开标与比价结果录入。

### 4.3 审批链（按金额分级）

| 金额区间 | 审批链 |
|----------|--------|
| < 1 万元 | 部门负责人 |
| 1 万（含）~ 10 万元 | 部门负责人 → 采购部 → 财务共享中心 |
| ≥ 10 万元 | 上述 + 分管副总；≥ 50 万元再加总经理 |

### 4.4 与其他系统的关系

- 审批通过的付款申请经服务总线推送至 FSS，由 FSS 完成付款并回写状态与凭证号；
- 供应商主数据与合同编号同步至 CRM，用于商机与合同的关联查询；
- 完整数据流见《组织与系统实体关系图谱》第二章。

## 第五章 IT 服务台（工单系统内部实例）

- **定位**：公司内部 IT 报障与运维工单平台，基于公司自研工单系统产品部署的内部实例，
  与对外销售的工单系统产品同名但为独立部署，不对外提供 SLA 承诺；
- **功能**：工单提交、多级派单、SLA 时限与自动升级、知识库联动、移动端处理、统计报表；
- **入口**：企业微信 → 工作台 → IT 服务台；
- **响应时效**：P1 15 分钟 / P2 30 分钟 / P3 4 个工作小时（详见《IT 支持与网络故障排查手册》1.2）；
- **与 CRM 的关系**：已做客户主数据与服务记录的打通，详见《组织与系统实体关系图谱》2.1。

## 第六章 财务共享系统（FSS）

- **定位**：财务共享中心统一作业平台，是开票信息、发票、报销核算、付款、预算的权威数据源；
- **常用模块**：客户与开票信息、发票开具、报销核算、付款管理、预算执行、成本中心；
- **入口**：PC 端为主，企业微信可接收待办与审批提醒；
- **原则**：对外提供的开票资料一律以 FSS 导出为准，不使用转录或截图件。

## 第七章 企业知识库（内部版）

- 按空间划分：人事制度、财务制度、IT 支持、产品与销售、培训与案例；
- 权限：空间级 + 文档级细粒度授权，涉密空间需申请；
- AI 问答入口：可按自然语言检索制度条款，答案附原文出处，出处以本手册及各制度原文为准；
- 文档沉淀机制：贡献 → 审核 → 发布 → 定期复审（超过 12 个月未复审的文档标记为"待复核"）。

---

## 第八章 账号与权限通用规则

1. 统一身份认证走企业微信，禁止共享账号；
2. 新账号由用人部门在 OA 提交《账号开通申请》，按岗位模板授权，不做个性化开权限；
3. 权限变更与离职停用统一由 OA 流程驱动，信息技术部 1 个工作日内执行；
4. 涉及客户数据、财务数据、合同数据的角色，默认最小权限，按需申请、到期自动回收；
5. 每季度由信息技术部牵头做一次权限复核，超期未使用的权限自动回收。
