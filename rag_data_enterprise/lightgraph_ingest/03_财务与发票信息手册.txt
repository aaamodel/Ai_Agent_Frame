# 财务与发票信息手册

> 版本：v1.0 | 维护人：财务部（财务共享中心）| 更新节奏：开票信息变更当日更新；制度修订后 3 个工作日内
> 适用范围：销售、售前、采购及全体员工的报销、付款、发票、预算事项。
> **本文件是财务制度与发票信息类问题的唯一权威依据。**

---

## 第一章 开票信息：字段构成与查询路径

### 1.1 查询路径（三选一，按推荐顺序）

| 优先级 | 查询路径 | 说明 |
|--------|----------|------|
| ① | **财务共享系统（FSS）** → 客户与开票信息 → 开票信息查询 | 唯一实时权威来源，可导出 PDF/图片版开票信息卡 |
| ② | **OA** → 财务服务目录 → 开票信息查询 / 开票申请 | 适合顺带发起开票申请的场景 |
| ③ | 联系财务共享中心（企业微信「财务共享」服务群） | 适合需要盖章纸质件或客户有特殊要求的场景 |

### 1.2 开票信息字段构成

| 字段 | 是否必填 | 说明 |
|------|----------|------|
| 单位名称 | 必填 | 须与营业执照登记名称完全一致，不得使用简称 |
| 纳税人识别号 | 必填 | 统一社会信用代码 |
| 注册地址 | 必填（专票） | 营业执照登记地址 |
| 电话 | 必填（专票） | 公司登记电话 |
| **开户银行** | 必填（专票） | 基本户开户行，须写支行全称 |
| **银行账号** | 必填（专票） | 基本户账号 |
| 发票类型 | 必填 | 增值税专用发票 / 增值税普通发票 |

### 1.3 使用规则（重要）

1. **开户行与账号以财务共享系统（FSS）实时数据为准。** 本手册不固化具体账号数字，
   避免账户变更或支行调整后产生过期信息；向客户提供的开票信息一律从 FSS 导出，不接受截图转录；
2. 开具增值税专用发票必须提供上表六项完整信息，缺任一字段财务共享中心有权退回申请；
3. 开票信息发生变更时，由财务共享中心在 FSS 统一更新并同步至 CRM 客户档案，
   其他部门不得自行修改对外提供的开票资料；
4. 对外提供开票信息时只提供我方开票资料，**不得向客户索取或留存客户方的银行账号等敏感信息**，
   客户侧涉税信息由客户自行提供；
5. 纸质盖章件有效期为出具之日起 30 个自然日，超期需重新申请。

### 1.4 常见问法澄清

| 容易混淆的说法 | 正确口径 |
|----------------|----------|
| "开票信息在系统里存着吗" | 存在，权威源是财务共享系统（FSS），不是 CRM，也不是采购与合同审批系统 |
| "能不能直接从合同里复制" | 不可以，合同中的开户行可能为旧支行名，必须以 FSS 为准 |
| "销售自己能不能改" | 不能，销售仅可查询与导出，变更由财务共享中心维护 |

## 第二章 发票开具与红冲

### 2.1 开票申请

| 环节 | 时限 | 责任方 |
|------|------|--------|
| 销售在 CRM 提交开票申请（关联合同编号） | 客户提出后 1 个工作日内 | 销售 |
| 财务共享中心审核资料完整性 | 2 个工作小时内 | 财务共享中心 |
| 开具并寄出 / 推送电子发票 | 收到完整资料后 3 个工作日 | 财务共享中心 |
| 客户签收确认 | 收到后 5 个工作日内回执 | 销售 |

### 2.2 专用发票的额外要求

- 客户须具备一般纳税人资格，提供税务登记证或一般纳税人证明；
- 新客户首次开票须同时提供营业执照复印件（加盖公章）；
- 单次开票金额超过 50 万元的，需附合同复印件。

### 2.3 红冲与作废

- 开票信息错误、客户退票、合同金额变更均可申请红冲；
- 红冲流程：销售在 CRM 提交红冲申请并上传客户书面说明 → 销售负责人审批 → 财务共享中心执行；
- 已认证的专用发票红冲须取得客户《开具红字增值税专用发票信息表》。

## 第三章 报销与付款

### 3.1 报销流程

```
OA 提交报销单（附发票与业务凭证） → 直属上级审批 → 部门负责人审批
→ 财务共享中心审核（3 个工作日） → 付款（每周三、周五付款日） → 回单归档
```

### 3.2 报销时限与要求

- 费用发生后 **30 个自然日**内提交；跨年度单据不得迟于次年 1 月 10 日；
- 发票抬头与纳税人识别号必须与第一章口径一致，简称或错字一律退回；
- 单笔报销需说明业务事由并关联对应客户或项目；
- 电子发票需上传原始 PDF 文件（不接受截图）；
- 连号发票、大额整数发票、第三方代开发票将触发财务复核。

### 3.3 差旅标准

| 项目 | 标准 | 说明 |
|------|------|------|
| 市内交通 | 据实报销 | 原则上公共交通；同城县际出差需说明 |
| 长途交通 | 高铁二等座 / 经济舱 | 高管可乘高铁一等座；超标准需部门负责人审批 |
| 住宿（一线城市） | 500 元/晚 | 凭发票据实在标准内报销 |
| 住宿（其他城市） | 350 元/晚 | 同上 |
| 出差补贴 | 100 元/天 | 按自然日计，不需发票 |

### 3.4 付款与收款

- 对客收款：以合同约定的公司基本户为准，账户信息由财务共享中心统一对外提供；
- 对外付款：由采购与合同审批系统（PAS）发起的付款申请推送至 FSS 后统一支付，
  数据流见《组织与系统实体关系图谱》第二章；
- 付款日：每周三、周五；紧急付款需财务部负责人审批。

## 第四章 预算与成本中心

| 事项 | 入口 | 时限 |
|------|------|------|
| 成本中心新增 / 变更 | OA → 财务服务目录 → 成本中心申请 | 财务共享中心 2 个工作日内办结 |
| 年度预算编制 | 每年 11 月由财务部下发模板，各部门 15 个工作日内提交 | — |
| 预算调整 | OA 预算调整单，超 10% 需总经理审批 | — |
| 预算执行查询 | 财务共享系统 → 预算执行 | 按月更新 |

**规则**：成本中心是费用归集与预算控制的最小单位，所有报销与付款单据必须挂载成本中心，
无成本中心的单据不予受理。

## 第五章 系统与归口对照（防混淆）

| 系统 | 管什么 | 不管什么 |
|------|--------|----------|
| 财务共享系统（FSS） | 开票信息、发票开具、报销核算、付款、预算、成本中心 | 采购审批、合同审批 |
| 采购与合同审批系统（PAS） | 采购申请、合同审批、供应商准入、付款申请发起 | 发票开具、账务核算 |
| CRM 系统 | 客户档案、合同与回款记录、开票申请发起 | 不做账务处理 |
| OA 系统 | 报销单、预算单等流程入口 | 不存储权威开票信息 |
