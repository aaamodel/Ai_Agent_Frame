# IT 支持与办公网络故障排查手册

> 版本：v1.0 | 维护人：信息技术部（IT 运维组）| 更新节奏：网络架构或服务商变更后 5 个工作日内更新
> 适用范围：总部与分支机构全体员工的办公网络、终端、账号与办公软件问题。
> **本文件是 IT 支持类问题的唯一权威依据。** 涉及机房、运营商专线的对外沟通由信息技术部统一口径，
> 其他部门不得对外发布故障原因结论。

---

## 第一章 报障渠道与响应时效

### 1.1 报障入口

| 渠道 | 入口 | 适用 |
|------|------|------|
| IT 服务台（工单系统内部实例） | 企业微信 → 工作台 → IT 服务台 → 提交工单 | 所有非紧急问题，**推荐** |
| IT 值班电话 | 总部内线 8000（7×24） | P1 级故障（全员/全网点受影响） |
| IT 值班群 | 企业微信「IT 应急值班」群 | 故障期间的进展同步 |

> 说明：公司内部的 IT 服务台基于公司自研**工单系统**产品部署的内部实例，
> 与对外销售的工单系统产品同名但为独立部署（详见《内部业务系统使用手册》第五章）。
> 它与 CRM 系统的打通关系见《组织与系统实体关系图谱》第二章。

### 1.2 响应时效（SLA）

| 等级 | 判定标准 | 首次响应 | 定位结论 | 目标恢复 |
|------|----------|----------|----------|----------|
| P1 | 全网点或整栋办公楼网络/核心业务系统中断 | 15 分钟 | 1 小时内 | 4 小时内 |
| P2 | 单个楼层/部门受影响，或关键系统部分不可用 | 30 分钟 | 4 小时内 | 1 个工作日 |
| P3 | 单台终端、单个账号、单个外设 | 4 个工作小时 | 1 个工作日 | 3 个工作日 |

### 1.3 报障信息模板（提交工单时请一并填写）

1. 影响范围：只有我 / 我们部门 / 全公司；
2. 现象：完全断网 / 能上微信不能开网页 / 时断时续；
3. 发生时间：首次出现的具体时间点；
4. 终端信息：工位编号或楼层、有线/无线、电脑资产编号；
5. 已尝试的动作：重启、换网线、切手机热点等。

## 第二章 办公网络整体中断的分层定位

### 2.1 核心原则

**"内网全断了"不等于机房故障。** 机房只是链路中的一层，统计上更常见的成因是出口专线、
DHCP 地址池耗尽或认证系统异常。必须先做影响面确认，再自下而上分层验证，避免直接归因于机房。

### 2.2 分层模型（自下而上）

```
终端（网卡/网线/无线）
   ↓
接入层交换机（楼层弱电间）
   ↓
汇聚/核心交换机（总部核心机房）
   ↓
出口区（防火墙 / 上网行为管理 / DNS / DHCP / 认证系统）
   ↓
运营商专线（电信主用 / 联通备用）
```

### 2.3 逐层验证动作

| 层级 | 典型现象 | 验证动作 | 责任方 |
|------|----------|----------|--------|
| 终端 | 仅个别电脑无法上网 | 换网线/换端口/切手机热点对比；查看网卡是否被禁用 | 员工自查或 IT 远程 |
| 接入交换机 | 同一楼层或同一区域集体掉线 | 观察交换机指示灯；弱电间断电/环路排查 | IT 运维组 |
| 核心机房 | 全网点中断且内网服务器也不可达 | 机房动环告警（市电/UPS/温度）、核心交换机状态核查 | IT 运维组 + 机房管理员 |
| 出口区 | 能登微信但打不开网页；获取不到 IP | 查 DHCP 地址池占用率、DNS 解析、认证系统会话数 | IT 运维组 |
| 运营商专线 | 内网可通、外网全断 | 双专线切换测试（主备倒换）；向运营商报障并取工单号 | IT 运维组 + 运营商 |

### 2.4 快速判定口诀

- **内网服务器也开不了** → 问题在核心层及以上（机房 / 核心交换机）；
- **内网通、外网不通** → 问题在出口区或运营商专线；
- **只有网页打不开、微信正常** → 优先查 DNS；
- **提示"无 IP 地址"或拿到 169.254 段地址** → 优先查 DHCP 地址池；
- **时断时续且集中在上午开机高峰** → 优先查地址池耗尽或网络环路。

### 2.5 员工侧标准处置（在报障之后）

1. 先用手机热点恢复必要工作，不要反复重启电脑；
2. 在 IT 值班群同步「影响范围 + 现象 + 发生时间」三段信息；
3. 断网期间无法在 OA / CRM 提交的流程，**恢复后 24 小时内补录**，并在单据备注中写明断网时段；
4. 不要自行改动工位网络端口、私接路由器或交换机（私接设备是楼层环路故障的常见诱因）。

## 第三章 机房与基础设施概况

| 项目 | 现状 |
|------|------|
| 位置 | 总部 A 座 3 层核心机房（分支机构无独立机房，通过专线接入总部） |
| 供电 | 双路市电 + UPS，满载续航约 30 分钟，配柴油发电机手动切换预案 |
| 网络出口 | 双运营商专线：电信主用 500M、联通备用 300M，主备自动倒换 |
| 动环监控 | 温湿度、烟感、市电、UPS 状态接入监控平台，异常自动告警至 IT 运维组 |
| 出入管理 | 需 OA 提交《机房出入申请》并由信息技术部负责人审批，全程双人陪同 |

**对外口径**：涉及机房或运营商的故障原因，统一由信息技术部发布；未经确认不得向客户或外部
宣称"机房故障"。

## 第四章 常见故障速查表

| 现象 | 优先排查 | 自助动作 |
|------|----------|----------|
| VPN 连不上 | 账号状态、客户端版本、双因子令牌时间 | 重登企业微信令牌；仍失败则提交工单 |
| 邮箱收不到外部邮件 | 反垃圾隔离区、邮箱容量 | 登录网页版查隔离区；清理空间 |
| 打印机无法打印 | 队列是否卡单、驱动版本、网络打印服务器 | 清空队列重发；换默认打印机 |
| 账号密码遗忘 | 企业微信自助重置 | 企业微信 → 工作台 → 账号自助 → 重置密码 |
| 账号被锁定 | 连续输错 5 次锁定 30 分钟 | 等待自动解锁或联系 IT 值班电话 |
| 文件服务器访问很慢 | 是否处于备份窗口（每日 01:00–05:00） | 避开备份时段 |
| 视频会议卡顿 | 本地上行带宽、是否走代理 | 关闭视频只保留音频；改用手机入会 |

## 第五章 安全与合规红线

1. 禁止私接路由器、随身 WiFi、家用交换机接入办公网；
2. 禁止将办公终端同时接入外网与生产/客户专网（双网卡直连）；
3. 涉及客户数据的导出与外发，须走数据外发审批，不得通过个人网盘中转；
4. 发现疑似攻击或数据外泄迹象，立即拨打 IT 值班电话（内线 8000），先断网后取证。
