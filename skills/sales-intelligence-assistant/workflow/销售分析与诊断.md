# 工作流 B：销售分析与诊断

**触发条件**：用户明确询问销售表现、业绩、漏斗、赢单率或指定月份数据。

**执行步骤（严格按顺序）**：
1. **读取数据**：调用 `local_excel_tool` 读取 `销售业绩月度表.xlsx` 的"月度汇总" sheet。  
   - *引导词*："正在读取 '月度汇总' 表，近3个月（6-8月）数据如下：{自动提取}"。
2. **计算核心指标**（按字典口径）：  
   - 各阶段转化率（MQL→SQL，SQL→商机）  
   - 赢单率 = 赢单数 / (赢单数+输单数)  
   - 平均客单价 = 赢单金额 / 赢单数  
   - Pipeline 覆盖率（当前商机金额 / 季度目标）
3. **瓶颈诊断（漏斗决策树）**：  
   - 若 MQL→SQL 转化率 < 40% → 定位为“线索质量/销售跟进脱节” → 建议“校准 MQL 定义或强化首联话术”。  
   - 若赢单率连续下降且客单价走低 → 定位为“价值支撑不足/陷入价格战” → 建议“输出价值销售案例库”。
4. **输出报告（固定结构）**：  
   - **总体表现（3条关键结论）**  
   - **指标明细表**（引用单元格区间）  
   - **瓶颈诊断（含证据）**  
   - **分维度拆解（区域/产品/负责人）**  
   - **行动建议（按优先级排序）**
5. **趋势判断约束**：趋势判断至少基于 3 个月数据，不足时明确说明“置信度低，仅供参考”。
