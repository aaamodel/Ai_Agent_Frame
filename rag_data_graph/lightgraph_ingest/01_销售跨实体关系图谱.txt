# 销售跨实体关系图谱（跨表关联键与对账路径）

> **本文件的定位**：只描述销售域各类数据资产之间的**实体、关联键与对账路径**，
> 不重复任何单表的内容，**不引入任何新的业务事实**。
>
> **用途**：回答「A 和 B 是怎么对账的」「A 依赖哪些 B」「这些业务之间怎么关联」
> 这类**跨实体关联**问题。单条事实、单个数字、某段原文，应回到对应表或文档去取。
>
> **使用规则（对 Agent）**：
> 1. 问的是「某一个具体事实/数字/条款」→ 不要用本文件，用原文检索或直接读表；
> 2. 问的是「两个及以上实体之间的关系、关联键、对账口径」→ 用本文件；
> 3. 本文件的表名、字段名、编号规则全部取自各表格的「字段字典」sheet 与既有语料；
>    若本文件与「字段字典」冲突，**以字段字典为准**。

## 二、实体之间的关系边（关联键 + 对账口径）

| 关系 | 起点 → 终点 | 关联键 | 判定 / 对账口径 |
|------|-------------|--------|----------------|
| 线索 → 商机结果 | E1「线索编号」→ E3「线索编号」 | `LD-YYYYMM-XXX` | 台账「状态」为赢单/输单的记录，应能在输赢单明细中按同「线索编号」找到对应行（示例：`LD-202606-025` ↔ `WL-202606-01`） |
| 归档关系 | E3「台账关联」 | 取值「在台账」/「已归档」 | 「已归档」表示该行「线索编号」为 `—`，已不在当前活跃台账管线 |
| 输赢单 ↔ 案例库 | E3「记录编号」→ E7 的 `SC-` 编号 | `WL-202606-01` ↔ `SC-202606-01` | 案例编号与输赢单编号后段对应；**客户名冲突时以台账/输赢单明细的「公司全称」为准** |
| 台账 ↔ 月度汇总 | E1「状态 / 最近跟进日期」→ E2「月度汇总·月份」 | 无直接主键，**按月聚合** | 转化计入转化发生月；商机结果（赢单/输单）计入**关闭月** |
| 区域产品透视 ↔ 月度汇总 | E2「区域产品透视」合计行 ↔ E2「月度汇总」 | 季度 = 该季各月赢单金额之和 | 合计行自述对账公式：2026Q2 对账 = 04+05+06 月（91+72+68）；2026Q3 对账 = 07+08 月（57+53） |
| 市场活动 ↔ 台账 | E4「关联台账线索」→ E1「线索编号」 | `LD-YYYYMM-XXX` | 活动带来的线索编号应能在台账中查到 |
| 市场活动 ↔ 业绩 | E4「赢单金额(万元)」→ E2 | 无直接主键，按活动举办月归集 | 单赢单成本 = 总投入 ÷ 转化赢单数（E4「季度汇总」列） |
| 竞品 ↔ 输赢单 | E5「竞品名称」→ E3「竞争对手」 | 市场通称 | 「竞争对手」为 `—` 表示该单与竞品无关（非竞品原因赢单/丢单） |
| 竞品 ↔ 案例 / 时间线 | E5「竞品名称」↔ E5「动态时间线·竞品」↔ E7 `CCP-` 案例 | 竞品名称 | 动态时间线 = 对方外部动作（发布/促销/合作）；竞品成功案例 = 对方拿单记录 |
| 产品线 ↔ 意向 / 成交 | E6「产品线/版本」↔ E1「意向产品」↔ E3「产品线/版本」 | 产品线名一致 | 台账只有**产品线**粒度（无版本）；**版本**只出现在产品目录与输赢单明细 |
| 折扣权限 ↔ 角色 | E6「折扣权限·权限等级」↔ E1「负责人」角色 | 角色 | 折扣下限：销售代表 9.5 折 / 销售经理 9 折 / 销售总监 8.5 折；低于 8.5 折需总经理审批 |
| 阶段流转 | E1「状态」↔ E1「阶段流转规则·阶段」 | 阶段名 | 9 个阶段：线索 / MQL / SQL / 商机 / 方案验证 / 商务谈判 / 赢单 / 输单 / **搁置**；「搁置」= 连续 45 天无响应，90 天后回公海（与《销售方法论与商机资质判定手册》1.2 同口径） |
| 目标 ↔ 业绩 | E7 `TG-` ↔ E2「月度汇总」/「区域产品透视」 | 月份 / 季度 + 区域 | 考核维度必须对齐：`TG-` 可能按**区域**设定目标，而「月度汇总」是**全公司**口径，「区域产品透视」才是区域口径——跨维度直接相减会算错 |

## 三、常见跨实体问法的关联路径（示例）

**1）客户线索台账和销售业绩月度表之间是怎么对账的？**

```
E1 台账（状态=赢单/输单）
   └─ 按「线索编号」LD-YYYYMM-XXX
        → E3 输赢单分析表「线索编号」 → 取「关闭月份」+「金额(万元)」
             └─ 按「关闭月份」汇总 → E2 月度汇总·当月「赢单金额(万元)」
                  └─ 按「区域 × 产品线」交叉验证 → E2 区域产品透视
                       └─ 季度校验：Q2 = 04+05+06 月；Q3 = 07+08 月（表内合计行口径）
```

关键点：台账里只有「预估金额(万元)」，**成交金额以输赢单明细的「金额(万元)」为准**；
两张表之间唯一的硬关联键是**线索编号**，其余（月份、区域、产品线）都只能做聚合维度。

**2）某场市场活动到底带来了多少业绩？**
E4「关联台账线索」→ E1 →（E3 线索编号）→ 金额与关闭月 → E2 月度汇总；
单赢单成本（CAC）= E4 总投入 ÷ 转化赢单数。

**3）我们的单主要输给了谁？**
E3「竞争对手」→ E5「竞品名称」→ E5「动态时间线」（对方当期动作）；
赢单侧的同期案例见 E7 `CCP-`（竞品成功案例）。
