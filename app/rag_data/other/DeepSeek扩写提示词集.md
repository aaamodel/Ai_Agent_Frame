# DeepSeek 扩写提示词集（销售情报助手）

> 目的：当你手上有真实业务数据（真实客户、真实赢单、真实活动），但没空按格式一个个写文件时，把对应提示词复制到 **DeepSeek 聊天框**，填好"输入信息"即可生成**符合本技能数据结构**的内容，粘贴回对应文件即可。
> 适用范围：7 个新增文件 + 4 个原有可扩文件。每个提示词都"粘贴即用"，输出直接对齐 `sales-intelligence-assistant` 的字段口径。

---

## 0. 使用总则（先读）

1. **保持数据宇宙一致**：本助手所有文件共用一套"虚构种子数据宇宙"，方便你替换。扩写真实数据时请沿用同一套命名，避免两套对不上的账：
   - 我方销售：王强（华北总监）、李娜（华东）、张伟（华南）、陈静（西南）、销售运营
   - 我方产品：智能客服平台 / 工单系统 / 企业知识库；版本：标准版/专业版/旗舰版
   - 客户（示例）：中恒建设、雅膳食品、华南精工、西南优购、汇智软件园
   - 竞品：智齿、七鱼、易维、语雀
   - 区域：华北/华东/华南/西南；编号规则：案例 SC/CC/CCP、反馈 CF、培训 TR、目标 TG、活动 MA、线索 LD、输赢单 WL
2. **编号顺序**：新增条目编号顺延（如已有 SC-202608-01，新案例用 SC-202609-02）。
3. **落库后必做**：
   - `.md` 文件 → 重新上传 `sales_kb` 集合（覆盖同名文档）或追加段落；
   - `.xlsx` 文件 → 用 `local_excel_tool` 单格写/追加行，保持 ≤50 行；
   - 凡涉及金额/赢单的，更新后跑一次《数据资产使用总说明》第 4 节三项对账；
   - 若新增了"对 Agent 的新问题类型"，在 SKILL.md 资产地图与语言信号里补一行。
4. **禁止**：让 DeepSeek 编造客户证言原话、编造赢单金额——这些只能来自真实业务，AI 只负责"按模板组织语言"。
