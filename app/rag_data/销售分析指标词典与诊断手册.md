# 销售分析指标词典与诊断手册

> 版本：v1.0 | 维护人：销售运营
> 本手册统一所有销售分析口径：指标定义、计算公式、数据来源（对应《销售业绩月度表.xlsx》的字段）与漏斗诊断决策树。
> **任何分析报告中出现的指标，计算口径必须与本手册一致。**

---

## 第一章 核心指标定义

### 1.1 漏斗类指标

| 指标 | 计算公式 | 数据来源 | 健康参考区间 |
|------|----------|----------|--------------|
| 线索→MQL 转化率 | MQL 数 ÷ 新增线索数 | 月度汇总表 | 25%~40% |
| MQL→SQL 转化率 | SQL 数 ÷ MQL 数 | 月度汇总表 | 30%~50% |
| SQL→商机转化率 | 商机数 ÷ SQL 数 | 月度汇总表 | 40%~60% |
| 商机赢单率 | 赢单数 ÷（赢单数+输单数） | 月度汇总表 | 20%~30% |
| 整体线索转化率 | 赢单数 ÷ 新增线索数 | 月度汇总表 | 3%~5% |

**口径细则**：
1. 转化率按"当期发生转化的数量"统计，不按线索创建批次（简化口径，跨月转化归入转化发生月）；
2. 赢单率分母只含"已决出结果"的商机，进行中的商机不计入；
3. 台账中的商机阶段流转，以"状态"字段最近一次变更日期为准。

### 1.2 金额类指标

| 指标 | 计算公式 | 数据来源 |
|------|----------|----------|
| 赢单金额（ACV 口径） | 当期签约合同的首年订阅金额之和 | 月度汇总表 |
| Pipeline 金额 | 所有"商机"及以后阶段的预估金额之和 | 线索台账 |
| Pipeline 覆盖率 | Pipeline 金额 ÷ 下季度目标金额 | 台账 + 目标 |
| 平均单笔金额（平均客单价） | 赢单金额 ÷ 赢单数 | 月度汇总表 |

**Pipeline 覆盖率健康标准**：3.0 倍以上（按 20%~30% 赢单率反推）；低于 2.5 倍判定为下季度目标存在风险。

### 1.3 效率类指标

| 指标 | 计算公式 | 健康参考 |
|------|----------|----------|
| 销售速度（Sales Velocity） | (商机数 × 赢单率 × 平均客单价) ÷ 平均成交周期(天) | 趋势比绝对值重要 |
| 平均成交周期 | 各赢单商机"创建日期→赢单日期"天数均值 | 90~180 天 |
| 人均单产 | 赢单金额 ÷ 销售人数 | 对照当期目标 |
| 线索响应时效 | MQL 创建→销售首次触达的平均时长 | ≤24 小时 |

### 1.4 分维度拆解标准

销售分析至少支持三个维度的下钻，各维度取值与台账字段一一对应：
1. **区域**（华北/华东/华南/西南）；
2. **产品线**（智能客服平台/工单系统/企业知识库）；
3. **负责人**（销售代表姓名）。
渠道来源（市场活动/官网/转介绍/电销）作为第四维度按需使用。

## 第二章 漏斗诊断决策树

**入口**：发现某项转化率连续 2 个月低于健康区间下限，或环比下降超过 10 个百分点。

```
哪个阶段出了问题？
├─ 线索→MQL 低
│   ├─ 检查来源结构：低质量渠道占比是否上升？
│   ├─ 检查 ICP 匹配度：非目标行业/规模的线索占比？
│   └─ 行动：调整渠道投放配比 / 收紧 ICP 过滤规则
├─ MQL→SQL 低
│   ├─ 检查响应时效：首触是否超过 24 小时？
│   ├─ 检查触达质量：是否有标准化首触话术与需求确认清单？
│   └─ 行动：建立 MQL 24 小时响应 SLA / 首触 SOP 培训
├─ SQL→商机低
│   ├─ 检查 MEDDIC 缺口：D（决策标准）与 E（决策人）缺失是否集中？
│   ├─ 检查伪需求占比：痛点无业务场景佐证的商机占比？
│   └─ 行动：商机评审前移 / 需求调研模板强制使用
└─ 商机赢单率低
    ├─ 检查输单原因分布：价格型输单 >30%？
    │   ├─ 是 → 价值传递问题：报价前是否完成 ROI 论证？
    │   └─ 否 → 检查是否集中在某竞品/某阶段
    ├─ 检查阶段停留时长：商务谈判阶段停留 >60 天的商机占比？
    └─ 行动：Battle Card 更新 / 重点商机周复盘机制
```

**诊断纪律**：
1. 先定位"阶段"，再定位"维度"（该问题是否只存在于某区域/产品/负责人）；
2. 单维度归因（"都是 XX 的问题"）必须给出数据支撑，否则视为未完成诊断；
3. 每次诊断输出必须落到 3 条以内可执行行动，注明责任人与检查时间。

## 第三章 分析报告标准结构

所有销售分析输出统一按以下结构（顺序不可变）：

```
1. 总体表现：3 条以内的关键结论（每条必须有数字支撑）
2. 指标明细表：核心指标 × 近 3~12 个月（标注数据来源 sheet）
3. 瓶颈诊断：按决策树定位到阶段+维度，附证据
4. 分维度拆解：区域 × 产品 × 负责人的交叉表现
5. 行动建议：≤3 条，按预期收益排序，注明责任人与时间点
```

**计算可复现要求**：报告中每个数字标注来源（文件名 + sheet + 单元格区间或行号）；涉及计算必须展示公式与中间值，不允许直接给出无法追溯的结果。

**趋势判断规则**：任何"上升/下降"结论至少基于 3 个数据点；不足 3 期时必须声明置信度低并给出需要积累的数据。

## 第四章 常见误用与禁止事项

1. **禁止用单月数据下趋势结论**——单月波动在 B2B 销售中属于正常噪声；
2. **禁止用进行中商机计算赢单率**——会虚高或虚低，失真方向不可控；
3. **禁止混用 ACV 与合同总额**——多年期合同总额大于 ACV，报告中必须注明口径；
4. **禁止无来源的"行业普遍"表述**——行业基准引用《销售方法论手册》第五章的标准区间；
5. **负责人维度对比不公开**——涉及个人的对比数据仅在管理者请求时输出。
