## TR-202609-01 赢单复盘：从输单到赢单的 5 步法（新销售/2h）

- **核心要点**：
  1. 输单复盘必查输赢单分析表（如 WL-202606-11），先看原因分类；
  2. 赢单案例复用成功案例库（如 SC-202606-01 的 SLA 扭转法）；
  3. 竞品应对用话术库 + 竞品成功案例（如 CCP-202606-01）；
  4. ICP 判定用客户画像标准（P0 级线索特征）；
  5. 业绩分析用指标词典 + 销售业绩月度表（赢单率计算口径）。
- **案例支撑**：WL-202606-11、SC-202606-01、CCP-202606-01
- **材料**：销售方法论手册 + 话术库 + 指标词典

## TR-202609-02 竞品应对实战：智齿/七鱼怎么打（老销售/1.5h）

- **核心要点**：
  1. 智齿=价格战 → 不硬刚，转私有化/SLA/组合（话术库 1.1）；
  2. 七鱼 AI 2.0=演示压力 → 用客户真实 FAQ 盲测（SC-202606-01 避坑点 2）；
  3. 易维/语雀=垂直低价 → 强调联动与行业模板（SC-202606-02/SC-202607-01）；
  4. 促销收窄期（如智齿 2026-09）启动输单客户回收计划。
- **案例支撑**：CCP-202606-01、CCP-202607-01、竞品追踪台账动态时间线

## TR-202909-03 ICP 识别与线索打分（新销售/1.5h）

- **核心要点**：
  1. 按客户画像与 ICP 判定标准做 P0/P1/P2 分级；
  2. 负向信号一票否决（如预算冻结、竞品已签约）；
  3. MEDDIC 六要素逐项取证，不拍脑袋打分；
  4. 高优先级线索优先进入跟进计划（write_todos）。
- **案例支撑**：客户画像与 ICP 判定标准、客户线索台账 LD-202606-025

## TR-202909-04 报价与折扣合规红线（全员/1h）

- **核心要点**：
  1. 折扣权限：销售代表下限 9.5 折、经理 9 折（产品与报价表）；
  2. 9 折以下必须走审批，不得向客户承诺；
  3. 内部毛利/成本/折扣权限不得向客户输出（合规边界 3）；
  4. 价格最终决定权在销售负责人。
- **案例支撑**：产品与报价表"折扣权限"sheet、话术库 1.1

## 使用规则（对 Agent）

1. 用户问"新销售怎么培训/某个主题讲什么"时：按主题筛选，输出要点+案例支撑；
2. 培训要点可直接作为销售方法论手册补充；
3. 培训案例编号与成功/输单/竞品案例库关联，形成培训与实战闭环；
4. 新培训由销售运营按结构填写，每季度更新，Agent 不编造培训记录。
