## 2. 数据怎么装进框架（三条通道）

### 通道一：RAG 语料 → 知识库 `sales_kb`
静态知识（方法论/话术/标准）走向量库，入库后用 `rag_knowledge_search` 检索：

```bash
# 逐份上传（.md/.txt/.pdf 均在白名单内），13 份语料全部入同一个集合
curl -X POST http://localhost:8000/documents/upload \
  -F "file=@raw_data/sales_intel/销售方法论与商机资质判定手册.md" \
  -F "collection_name=sales_kb"
# ...其余 12 份语料同理（评测问题集不入库）
# 第三批 6 份：销售成功案例库 / 客户成功案例 / 竞品成功案例 / 客户反馈汇总 / 销售培训手册 / 销售目标与考核
```

### 通道二：Excel → `local_excel_tool` 直接读
动态业务数据（台账/业绩/输赢单/竞品）**不入向量库**，保持单一数据源 + 可写：

```
local_excel_tool(action="read", file_path="D:\\...\\raw_data\\sales_intel\\输赢单分析表.xlsx", sheet_name="输赢单明细")
```
路径必须绝对路径；文件挪位置时同步改 SKILL.md 的资产地图表。

### 通道三：外部情报 → `web_search` 实时取
竞品最新动态、客户公司新闻：先查竞品追踪台账（已有结构化结论），再用 `web_search` 补增量，输出必须带"来源+日期+可信度(A/B/C)"。

**划分原则**：会变的进 Excel（可更新、可对账），不变的进 RAG（可检索、带引用），别人的实时进 web_search。

## 3. 数据具体怎么用（问题 → 数据 → 动作）

### 3.1 "专业版报价 45 万能不能打 9 折？"
1. `rag_knowledge_search(sales_kb)` 查产品知识库 → 专业版标牌价；
2. `local_excel_tool` 读"折扣权限"sheet → 销售代表下限 9.5 折、经理 9 折；
3. 读"组合策略"sheet → 客服+知识库组合 9 折的替代方案；
4. 输出：40.5 万在经理权限内；9 折以下只能建议走审批，不得承诺。

### 3.2 "中恒建设这个客户现在什么情况？"
1. 读台账线索总表 → LD-202606-025，赢单，45 万，华北；
2. 读输赢单分析表 → WL-202606-01：预估 90 万旗舰版，预算收缩降级专业版成交 45 万；
3. 输出客户卡片 + 建议次年旗舰版扩容回访（版本降级成交客户是升级销售的优质池）。

### 3.3 "最近三个月赢单率为什么下滑？"
1. 读月度汇总 → 6/7/8 月赢单率 23.1%→18.2%→20.0%；
2. 读输赢单明细 → 27 个输单中价格竞争 9 单（全部输给智齿、集中在华东）、竞品方案 6 单、预算冻结 5 单；
3. 读竞品台账动态时间线 → 2026-06-01 智齿华东促销降价 30%（可信度 A）；
4. 读区域产品透视 → 华东客服平台 Q3 环比 -25%；
5. 结论闭环：**促销 → 华东价格战 → 赢单率下滑**，输出应对（避正面比价/转私有化场景/nurture 回访），引用话术库 1.1。

### 3.4 "智齿最近有什么动作？"
1. 读竞品台账 → 6/1 促销、7/22 延长、9/2 收窄（均为 A 级）；
2. `web_search` 补最新动态，标注来源日期可信度；
3. 关联输赢单明细量化影响（9 单）+ 给应对方案（话术库 1.1 + ICP 华东策略）。

### 3.5 "帮我出 8 月销售复盘"
月度汇总（数字）+ 输赢单明细（归因）+ 区域产品透视（结构）+ 指标词典（口径与决策树）四表联动，按 SKILL.md 工作流 C 的报告结构输出。

## 4. 数据治理规则（谁、什么时候、怎么更新）

| 资产 | 更新时机 | 操作方式 | 责任人 |
|---|---|---|---|
| 客户线索台账 | 每次跟进后即时 | Agent 按单格写协议更新（SKILL.md 台账更新协议） | 销售 |
| 输赢单分析表 | 商机关闭时新增；季度末归档台账中已关闭记录 | 追加行（逐格写入末尾） | 销售运营 |
| 竞品追踪台账·动态时间线 | 每周情报例会 | 追加事件行（日期/事件/影响/可信度） | 销售运营 |
| 竞品追踪台账·竞品档案 | 季度评审威胁等级 | 更新对应单元格 | 销售负责人 |
| 销售业绩月度表 | 每月结账日 | 追加月度行 + 刷新透视 | 财务/销售运营 |
| RAG 语料（方法论/话术/ICP） | 季度复盘修订 | 改 md → 重新上传 sales_kb | 销售负责人 |
| 评测问题集期望值 | **每次替换真实数据后必须同步** | 人工修订 | 上线负责人 |

**一致性对账点**（每次月度更新后检查，也是本次已修复的三处）：
1. 月度汇总某月"赢单数/输单数/赢单金额" == 输赢单明细该月计数/金额合计；
2. 区域产品透视季度合计 == 月度汇总该季度赢单金额之和（注意 Q3 截至当前月的部分季度口径）；
3. 台账中"赢单"记录的预估金额 == 输赢单明细对应"成交金额"（关闭后回写成交价，如中恒/雅膳 90→45）。

**台账与输赢单表的分工**：台账=活跃管线+近期关闭；输赢单分析表=关闭商机的唯一历史记录源（台账关联列"在台账/已归档"）。季度末把台账中关闭超 90 天的记录移入分析表后，从台账删除。

## 6. 上线验收流程（浓缩版）

1. 7 份语料上传 `sales_kb` → 重启服务确认技能被发现；
2. 按《销售助手评测问题集》20 题全量跑一遍，通过率 ≥90% 方可发布；
3. 重点盯 Q16（拒编造）、Q17（折扣越权）两题——安全边界比准确率更优先；
4. 上线后每月结账日执行第 4 节三项对账，每季度修订话术库与 ICP。
